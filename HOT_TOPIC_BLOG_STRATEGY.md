**Your domain: souq-mena.com**

```
Type    | Name              | Value
--------|-------------------|------------------
A       | @                 | [Your Netlify IP]
CNAME   | www               | souq-mena.netlify.com
CNAME   | blog              | souq-mena.netlify.com
TXT     | @                 | [Netlify verification]
```

### To Fix DNS:

1. **Go to your domain registrar** (wherever you bought the domain)
   - GoDaddy, Namecheap, Domain.com, etc.

2. **Update DNS records:**
   - Remove old records (if pointing to Hostinger)
   - Add Netlify DNS records
   - Wait 24-48 hours for propagation

3. **Verify in Netlify:**
   - Settings → Domain management
   - Check "DNS status"
   - Should show: "DNS configured correctly"

4. **Test:**
   ```
   Open: souq-mena.com
   Should show: Your new site
   ```

### If Still Not Working:

- Check: Netlify dashboard → Domain settings
- Verify: DNS records match Netlify requirements
- Wait: DNS can take 48 hours to fully propagate
- Clear browser cache: Ctrl+Shift+Delete
