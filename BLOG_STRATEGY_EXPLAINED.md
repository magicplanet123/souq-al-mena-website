## 🔗 HOW TO LINK (Opening New Window)

### **In Blog Posts:**
```html
<!-- Link to another blog (same window - makes sense) -->
<a href="../blog/ai-automation-2024.html">Learn more about AI</a>

<!-- Link to main website (NEW WINDOW - get them back to blog) -->
<a href="../trading/" target="_blank" rel="noopener noreferrer">View our trading services</a>
```

### **In Main Website:**
```html
<!-- Link to blog (NEW WINDOW - so they come back) -->
<a href="blog/" target="_blank" rel="noopener noreferrer">Read our latest articles</a>

<!-- Internal links (same window - no ads anyway) -->
<a href="recruitment/">Our recruitment services</a>
```

### **Logic:**
```
✅ Blog → Blog article: SAME window (stay reading)
✅ Blog → Main site: NEW window (keep blog open, they come back)
✅ Main site → Blog: NEW window (keep main open, they come back)
✅ Main site → Main site: SAME window (normal browsing)
```
